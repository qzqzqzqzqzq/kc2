# 本次运行中的失败与修正

1. **网络下载超时和 SSL 重置**：Hugging Face 直连不稳定；使用用户提供的 7897 代理和分块续传补齐。最终本地权重 SHA-256 与官方头信息一致，PyTorch 与 CUDA 组件也进行了校验。失败日志保留在 `logs/`。
2. **Python 版本兼容性**：基础环境是 Python 3.14，改用独立 Python 3.11 环境；不改动基础环境的软件包。
3. **缺少 CUDA Toolkit**：显卡驱动可用，但编译器缺失。使用 NVIDIA 官方 nvcc、cudart、CCCL 12.8 redistributable，配合已有 Visual Studio 2022 编译 gsplat 1.5.3。
4. **pycolmap 3.10 DLL 初始化失败**：升级到 3.11.1 后可导入；官方导出代码中的 `Image.registered` 在新 API 中不存在，做了兼容判断。实际注册相机数量已验证。
5. **Windows 中文绝对路径**：COLMAP 写文件时出现 UnicodeDecodeError。通过 Python 切换工作目录后传入英文相对路径修复，不修改项目目录名。
6. **TUM 候选画面的运动模糊**：`data/desk/contact.png` 保存了候选图，部分图有明显模糊。本轮按展示目标选择 VGGT 官方工程车示例，未宣称在 TUM 上获得视频中的效果。
7. **第一轮拟合质量有限**：3,500 步的训练视图平均 PSNR 为 19.40 dB；最终 12,000 步为 20.77 dB。两者均为同一输入集的拟合诊断，不是独立测试成绩，也不是消融实验。
8. **仍然存在的视觉问题**：背景出现模糊、拉伸、漂浮结构；部分插值视角的车身细节不如输入照片锐利。已通过真实视频逐段抽帧检查主体可辨识，没有把这些伪影隐藏成“论文级重建”。`outputs/kitchen_12/train_00001.png` 保存初始渲染，其他训练阶段图片及最终渲染也保留供后续分析。

本轮已完成一个可运行的简化核心基线。公开数据集定量评测、标准方法对比、开放性改进方向及消融仍需后续实施。
